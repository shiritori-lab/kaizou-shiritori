# 改造しりとりによるLLM対戦実験

## 概要

LLM同士に改造したしりとりを行わせるための実験プログラムです。

通常のしりとりでは、1ターンに1つの単語を使用しますが、
本実験では1ターンに使用できる単語数を変更し、
LLMの行動がどのように変化するかを調べます。

## 実験内容

今回の実験では、以下の3条件でLLM同士を対戦させました。

* 1ターンに使用できる単語数：1
* 1ターンに使用できる単語数：3
* 1ターンに使用できる単語数：10

各条件について30回の対戦を行いました。

使用したプロンプトは `prompt11.txt` に記載しています。

## ファイル

* `shiritori_ver1_4.py`
  改造しりとりの実験プログラム

* `prompt11.txt`
  LLMに使用したプロンプト

* `shiritori_log_v3_P11_n=1.csv`

* `shiritori_log_v3_P11_n=3.csv`

* `shiritori_log_v3_P11_n=10.csv`

  実験結果のログ。`P11` は使用したプロンプト番号、`n=` は1ターンに使用できる単語数を示します。

## 辞書データ

しりとりの合法手判定には、日本語辞書データを使用しています。

使用した辞書データ自体は本リポジトリには含めていません。

### 入手元

[辞書の公式サイト]
https://clrd.ninjal.ac.jp/unidic/

使用した辞書の種類・バージョンについては、実験環境に合わせて記載してください。

### JSONファイル

実行には `shiritori_dictionary.json` が必要です。

このファイルは、公式配布元から取得した辞書データを、
実験環境で利用するためにJSON形式へ変換したものです。

辞書データの利用・再配布については、提供元のライセンス・利用規約に従ってください。

## 実験条件

* 対戦形式：LLM vs LLM
* 対戦回数：各条件30回
* 条件：1 / 3 / 10単語
* 辞書：上記の日本語辞書
* 勝敗判定：プログラムによる自動判定

## 注意

本リポジトリは現在開発中の実験用コードです。

実験結果は、LLMの能力全般を評価するものではなく、
今回設定したしりとり環境における結果です。
